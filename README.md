# Judul Projek Akhir
Monitoring Tandon Pintar

# Deskripsi
Tandon air berfungsi sebagai media penyimpanan untuk menjaga ketersediaan air secara kontinu. Namun, pemantauan tandon yang masih dilakukan secara manual dinilai kurang efisien karena memerlukan pengawasan langsung, terutama pada tandon yang berada di lokasi sulit dijangkau. Kondisi tersebut dapat menyebabkan kelalaian pengisian air, seperti air meluap dan pemborosan penggunaan air. Oleh karena itu, diperlukan sistem pemantauan berbasis Internet of Things (IoT) yang mampu memantau ketinggian dan suhu air secara real-time. Sistem ini menggunakan sensor ultrasonik untuk mengukur ketinggian air dan sensor DS18B20 untuk membaca suhu air. Data sensor diproses oleh ESP32 dan dikirim melalui jaringan WiFi ke platform monitoring seperti Kodular sehingga pengguna dapat memantau kondisi tandon secara praktis dan efisien.
